## ✨ المميزات الرئيسية (Key Highlights)

1. **الهوية البصرية الفاخرة (Dark & Gold Luxury Aesthetics):**
   * تصميم مستوحى من أفخم اللاونجات العالمية بتدرجات الأسود الملكي (`#070709`) والذهب اللامع (`#D4AF37`).
   * تأثيرات الزجاج الداكن (Dark Glassmorphism) مع حدود ذهبية متوهجة عند التفاعل.

2. **تصوير سينمائي واستوديو بالذكاء الاصطناعي (Studio Photography):**
   * خلفية سينمائية لأجواء اللاونج الداخلية مع إضاءة خافتة وبخار شيشة ناعم.
   * تصوير استوديو عالي الدقة (8K) لمنتجات الشيشة الكريستالية، محاصيل القهوة المختصة، المشروبات، والشاي المغربي والحلويات.

3. **تجربة تفاعلية وبطاقات 3D (Interactive Motion Design):**
   * بطاقات منتجات تفاعلية مع تتبع حركة المؤشر (Spotlight Effect) وتكبير ناعم (Hover Zoom).
   * سلايدر للأصناف الأكثر طلباً في اللاونج (Lounge Bestsellers).
   * نافذة تخصيص سريعة (Customization Modal / Bottom Sheet) لاختيار نوع الرأس (تفاح، أناناس)، آيس بازوكا، كثافة الدخان، وحجم ومكونات المشروبات.

4. **نظام طلبات وطاولات متكامل (Ordering & Table Management):**
   * سلة مشتريات منبثقة مع تحديث فوري للأسعار والخيارات.
   * نظام الجلسات واختيار رقم الطاولة (VIP Lounge, Indoor, Outdoor Terrace).
   * دعم كامل لاتجاه الكتابة العربي (RTL) مع خيار التبديل للإنجليزية.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Export)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Animations & Motion**: [Framer Motion](https://www.framer.com/motion/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **State Management**: React Context & Hooks
* **Type Safety**: TypeScript
